# Personal working agreements

- Read the repository's instructions and existing implementation before changing code.
- Keep changes focused on the requested outcome and preserve unrelated work.
- Verify changes with the repository's relevant checks; report what ran and any limitations.
- Keep credentials and private runtime state out of commits and logs.
- Ask before destructive operations, publishing, or changing access permissions.

## Skills

- `review-changes`: review the current diff for correctness and missing validation when asked to review changes. Load its `SKILL.md` from your agent's skills directory.
